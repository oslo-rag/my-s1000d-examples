# S1000D Portfolio – Oslo RAG

**Personal showcase of clean, hand-crafted S1000D Data Modules**  
Built from scratch using official S1000D Issue 5.0 schemas and Oxygen XML templates.

---

## 📋 What I Did
- Created **fully compliant** Data Modules from zero (no copy-paste from examples)
- Followed strict S1000D naming conventions, issue control and CSDB structure
- Hand-crafted:
  - Descriptive module
  - Procedural (maintenance) module
  - Illustrated Parts Data (IPD) module
- Focused on readability, minimalism and real-world usability

3. Or drag the file into any S1000D viewer / CSDB system
