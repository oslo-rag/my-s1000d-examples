TOOLS & MATERIALS REQUIRED
Torque wrench (0-20 Nm)
10 mm socket set
Coaxial connector tool
New M8 bolts (x4)
Antenna mounting detail with coaxial feed
PROCEDURE
4 steps • Follow sequentially
1
Remove the four mounting bolts

Carefully loosen and remove the four M8 mounting bolts from the antenna base. Retain bolts for inspection if required.

🔩
2
Disconnect coaxial cable

Gently unscrew and disconnect the coaxial cable connector from the antenna feed. Use proper tool to avoid damaging threads.

📡
3
Install new antenna Torque 12 Nm

Position the new antenna on the base. Install new bolts and torque to exactly 12 Nm using calibrated torque wrench in cross pattern.

🛠️
4
Reconnect coaxial cable

Reattach the coaxial cable to the new antenna. Hand-tighten then use tool for final ¼ turn. Ensure secure connection without over-torquing.

🔌
✅
FINAL STEP • VERIFICATION

Perform full functional test of the radar system after replacement. Verify signal strength, alignment and operation before returning to service.
